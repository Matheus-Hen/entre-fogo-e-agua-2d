# Referências e identidade visual

O painel interno reúne Magnus (quatro vistas), fogo, água e arena ASDA, disponíveis no [catálogo](../README.md).

Estilo proposto: fantasia contemporânea, personagem ilustrado/anime e instalações industriais. Fogo #E17A3C / #FFD166; água #259EBC / #7BDFF2; estruturas #152C3D / #526878; texto #F4F1E8. Valores propostos, não amostrados.

Exploração superior levemente inclinada e combate com arena frontal. Adaptar a perspectiva de Magnus; preservar silhueta e roupa. Usar texto e ícones junto às cores. Regras completas no [GDD](../../docs/GDD-v0.2.md#direção-visual-e-referências).
